## 13/11/2026 — Une propriété CSS est-elle utilisable ?

- **Source** : [Baseline (compatibility) - Glossary | MDN](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility) — MDN 

- **Ce que j'ai appris** : 
- Un mot clef est compatible avec tout les navigateur ayant une version créer il y a moins de 2 ans et demi si il est marque dans baseline widely avaible donc presque tout les navigateur. 

- Tant dis que si elle est marque comme baseline newly avaible elle n'est compatible qu'avec la derniere version stable ( derniere realise)
